# Veda Technology – Task 18

## Region Performance

### Project Objective
Compared sales and profit across different regions to understand regional performance.

### Tools Used
- Microsoft Excel / WPS Office
- Sample Superstore Dataset

### Work Completed
- Created a Region Summary table.
- Calculated Total Sales for Central, East, South, and West.
- Calculated Total Profit for each region.
- Compared regional sales and profit.
- Created a clustered bar chart for regional comparison.

### Region Summary

| Region | Total Sales | Total Profit |
|---|---:|---:|
| Central | ₹496,479.63 | ₹38,941.25 |
| East | ₹683,440.29 | ₹93,279.49 |
| South | ₹382,250.15 | ₹45,126.92 |
| West | ₹728,355.61 | ₹108,729.71 |

### Key Findings
- West has the highest total sales among the four regions.
- West also has the highest total profit.
- South has the lowest total sales.
- Regional comparison helps identify differences in sales and profitability.

### Conclusion
The Region Performance analysis demonstrates how Excel can be used to group sales data by region and compare both sales and profit using a summary table and bar chart.
