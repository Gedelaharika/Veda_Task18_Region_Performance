# Veda Technology – Task 17

## Monthly Sales Trend

### Project Objective
Summarize sales by month and visualize the sales trend over time.

### Tools Used
- Microsoft Excel / WPS Office
- Sample Superstore Dataset

### Work Completed
- Used the Order Date field from the Superstore dataset.
- Created a monthly sales summary from January 2023 to December 2026.
- Calculated total sales for each month using Excel formulas.
- Formatted monthly sales values as currency.
- Created a line chart to visualize the monthly sales trend.
- Kept the original Raw_Data sheet unchanged.

### Key Finding
The monthly sales analysis shows how sales values change over time and helps identify periods with relatively higher and lower sales.

### Chart
A line chart titled **Monthly Sales Trend** was created to visualize the monthly sales pattern.

### Conclusion
Monthly sales analysis provides a simple way to understand sales performance over time and identify changes in the sales trend.
